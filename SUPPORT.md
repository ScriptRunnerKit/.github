# Getting help

- **Documentation**: start with the README of the project — it covers installation, configuration and examples.
- **Questions and ideas**: open an issue in the project repository using the *Question* or *Feature request* form.
- **Bugs**: open an issue with the *Bug report* form, including the versions you use and a minimal way to reproduce.
- **Security issues**: never in public — follow the [security policy](SECURITY.md).

Please search existing issues first; adding details to an open issue helps more than a duplicate.
