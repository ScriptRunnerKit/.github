# ScriptRunnerKit/.github

Organization-wide defaults for [ScriptRunnerKit](https://github.com/ScriptRunnerKit):

- `profile/README.md` — the organization profile page.
- Community health files used by every repository that does not have its own: [Code of Conduct](CODE_OF_CONDUCT.md),
  [contributing guide](CONTRIBUTING.md), [security policy](SECURITY.md) and [support](SUPPORT.md).
- Issue forms and the pull request template in [`.github/`](.github).
